# Calculadora em Java

Calculadora de console feita em Java, com as quatro operações básicas.

## Funcionalidades
- Soma, subtração, multiplicação e divisão
- Tratamento de erro para divisão por zero
- Validação de entrada (evita quebrar com valores inválidos)

## Tecnologias
- Java

## Como rodar
```bash
cd src
javac Main.java
java Main
```
